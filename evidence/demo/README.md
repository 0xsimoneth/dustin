## The script

The shot list, the exact commands in order, the terminal and browser setup and the reference values to compare a take against are in [`docs/demo-video-script.md`](../../docs/demo-video-script.md). The builder asked for the rehearsal to live there, so this page points to it: story E4-S6's criterion AC-E4-S6-3 names `evidence/demo/script.md` for the shot list and commands, and this pointer meets it. After a testnet reset the video is re-recorded from the same script on a freshly built fixture.
