## How the records are checked

`npm run evidence:check` with its default files ([`scripts/evidence-check.mjs`](../../../scripts/evidence-check.mjs)) checks this directory as well:

- each file must be named after its transaction and hold Horizon's record of it (its hash, ledger, close time, result and envelope); this part needs no network and holds after the reset;
- while the testnet keeps them, Horizon's answer for each transaction must equal the stored record in its ledger, close time, result and envelopes;
- every transaction that one of the seven documents cites, listed in a code span or a table cell or linked on Horizon or StellarExpert, must have a record here or in a run directory, unless its line says the envelope was never on the ledger.

## Reading a record

`envelope_xdr` is the whole signed envelope; for a fee bump it is the fee-bump envelope, `fee_account` is the account that paid, and `fee_bump_transaction` and `inner_transaction` give both hashes. `result_xdr` is the result, and `successful` says whether it applied. The XDR decodes with the JavaScript SDK (`TransactionBuilder.fromXDR(envelope_xdr, "Test SDF Network ; September 2015")`) or in Stellar Lab's XDR viewer (https://lab.stellar.org/xdr/view).
